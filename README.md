

## Офисная сеть по HTTP

Сайт доступен на `http://192.168.10.162:3003` для устройств в одной сети; Docker публикует только порт приложения на всех интерфейсах. Supabase, база и Studio сохраняют прежние настройки портов. Для Nuxt dev используйте `npm run dev` (он уже слушает `0.0.0.0`); перед этим остановите Docker-приложение, занимающее порт: `docker compose stop app`.

После входа личное хранилище открывается без отдельного мастер-пароля. Записи хранятся зашифрованными на сервере, используя `NUXT_SHARED_VAULT_KEY`, как и общие хранилища. Старые браузерные хранилища автоматически определяются; пользователь один раз вводит прежний мастер-пароль для переноса записей. Неверный пароль не меняет старые данные. После переноса прежний браузерный клиент не может перезаписать хранилище. Сохраняйте серверный ключ вместе с резервной копией базы. Через пять минут бездействия выполняется выход из аккаунта.

HTTP не защищает передаваемые логины, пароли и токены от перехвата в сети. Шифрование записей в базе этого ограничения не устраняет.


## Взаимосвязь и дополнительные поля

В боковом меню «Взаимосвязь» открыт интерактивный граф D3. Режимы: общие слова в названиях, одинаковые домены сайтов, ручные связи или всё вместе. Узлы перемещаются мышью, масштаб меняется колесом/жестом, выбор карточки открывает сведения и переход к редактору. Граф использует только доступные записи выбранного хранилища (или всех хранилищ). На нём нет паролей, логинов и значений дополнительных полей. Для больших наборов показываются первые 300 совпадений; поиск и переключение хранилища сужают выборку.

Редактор карточки поддерживает до 24 дополнительных полей типов «Текст», «Секрет» и «Ссылка», а также до 50 исходящих ручных связей. Связь указывает другую карточку, необязательные поля на каждом конце и описание. Входящие связи видны в редакторе целевой карточки. Связь не выдаёт дополнительных прав: если второй конец недоступен или удалён, он не попадает на граф. Секретные значения в карточках маскируются и доступны через копирование.

Общее хранилище переименовывает владелец в настройках переключателя хранилищ; личное переименовывается там же отдельно. Изменения имени общего хранилища защищены той же транзакцией и проверкой ревизии, что и изменения состава участников.

Новые хранилища создаются без базовых категорий. Скрипт `node --env-file=.env scripts/remove-default-categories.mjs` удаляет оригинальные категории «Работа», «Личное», «Финансы» и «Приложения» из существующих серверных хранилищ, сохраняя все карточки и переводя их в «Без категории». Пользовательские категории и переименованные исходные категории сохраняются. Для прежних браузерных хранилищ очистка выполняется при штатном переносе по мастер-паролю.

Автоматический режим «По дополнительным полям» объединяет одинаковые пары название/значение (без учёта регистра и лишних пробелов), например «Хостинг: TimeWeb». Такой узел также соединяется с доступной карточкой, в названии которой значение встречается отдельным словом или фразой — например «TimeWeb Cloud». Разные поля с одинаковым значением сохраняют отдельные узлы. Секретные поля исключены из автоматического сопоставления и поиска на графе.
