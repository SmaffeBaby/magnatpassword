
## Кэш запросов и уведомления

TanStack Vue Query хранит ответы только в памяти вкладки, отдельно для каждого аккаунта: личное хранилище, `/api/workspace` (общие хранилища и карточки с общей проверкой прав), уведомления, страницы истории PDF и данные админ-панели. Свежие ответы используются повторно в течение минуты; одновременные запросы объединяются. После изменений соответствующий кэш обновляется или помечается устаревшим. Кнопки «Обновить» запрашивают свежие данные принудительно. При выходе, смене аккаунта и блокировке хранилища запросы отменяются, кэш очищается; в localStorage и SSR payload он не записывается.

Общие данные и уведомления проверяются раз в минуту только в открытой активной вкладке с доступом к сети; при возвращении на вкладку обновляются устаревшие данные. Фильтры остаются в Pinia.

Для очистки уведомлений применяется миграция `009_notification_dismissal.sql`. Кнопка «Очистить всё» удаляет содержимое уведомлений аккаунта на сервере, включая записи за пределами показанных 100 уведомлений. Остаётся только техническая отметка с ключом дедупликации: прежнее напоминание не появляется снова после обновления. Новые события и следующие сроки напоминаний продолжают поступать. Очистка не меняет уведомления других пользователей.
